### Changes made

`python data/gen_d2.py` writes `data/d2.jsonl`:

- Each matrix is parsed from LaTeX into a list of rows. The original `problem_latex` and `answer_latex` are kept in every record.
- Each runnable problem is given a `problem` text in this repository's format, so it reaches the agents the same way a D1 problem does.
- Rank problems are mapped to the `rref_rank` topic, which also asks for the RREF, because the certificate needs it. The RREF comes from SymPy.
- A 20% dev / 80% test split is added, stratified by task and size, seed 20261024. LinAlg-Bench has no split, and PREREGISTRATION.md s4.2 does not set one.

### What can be run

All 660 problems are in `data/d2.jsonl`. Only 210 are marked `runnable`.

| Task | Problems | Runnable | Excluded because |
|---|---:|---:|---|
| determinant | 150 | 150 | |
| rank | 60 | 60 | |
| eigenvalue | 90 | 0 | Answers are irrational, rounded to 4 decimals, so they cannot take an exact certificate |
| matrix_vector, multiplication, matrix_power, nullity, trace, transpose | 360 | 0 | Outside the core 6 topics (PREREGISTRATION.md s1) |

For all 210 runnable problems, the determinant or rank computed by SymPy equals the answer published in the dataset. `gen_d2.py` stops if any differ.
